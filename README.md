# Customer Churn Prediction & Analytics Dashboard

An end-to-end customer churn analytics project built with Python,
CatBoost, Pandas, Scikit-learn and Streamlit.

The project generates a synthetic customer dataset, performs data
cleaning and feature preparation, trains churn models, estimates churn
probability, creates customer risk tiers, performs K-Means customer
segmentation, and presents the results through an interactive Streamlit
dashboard.

## Dashboard

The Streamlit dashboard provides six business-focused views:

-   **Overview** --- customer KPIs, churn distribution, risk
    distribution, revenue at risk, and key churn breakdowns.
-   **Churn Analysis** --- churn rates across contract, payment method,
    internet service, gender, number of services, tenure, and predicted
    probability.
-   **Customer Segmentation** --- K-Means customer segments with
    service, revenue, tenure, churn, and probability profiles.
-   **Risk Analysis** --- risk-tier distribution, probability
    vs. monthly charges, risk composition by contract, and highest-risk
    customers.
-   **Customer Explorer** --- inspect an individual customer's personal,
    subscription, service, and model information.
-   **Data Explorer** --- filter customers by contract, internet
    service, risk tier, and churn status, then download the filtered
    data as CSV.

## Dataset

The final dashboard dataset contains **30,000 customer records** and 36
columns.

Important fields include:

-   Customer information --- ID, name, gender, age, marital status,
    occupation, dependents
-   Financial information --- monthly income, income category, monthly
    charges, total charges
-   Location --- city, state, ZIP
-   Customer lifecycle --- join date and tenure
-   Services --- phone, multiple lines, internet, security, backup,
    device protection, tech support, TV and movie streaming
-   Subscription --- contract, paperless billing, payment method
-   Churn information --- churn probability, actual churn, model
    prediction, predicted churn probability
-   Analytics outputs --- risk tier and customer segment

The project uses a synthetic dataset generated by the included
data-generation pipeline.

## Machine Learning

### Churn Classification

A CatBoost classifier is trained to predict customer churn.

The model training notebook reports the following test-set results at
the 0.5 classification threshold:

  Metric        Result
  ----------- --------
  Accuracy       0.702
  Precision      0.384
  Recall         0.766
  F1-Score       0.511
  ROC-AUC        0.803

The notebook also evaluates multiple classification thresholds and
records an F1-based threshold selection.

### Churn Probability Model

A second CatBoost model is used to estimate
`PREDICTED_CHURN_PROBABILITY`.

The model-training notebook reports:

  Metric        Result
  ----------- --------
  Accuracy      0.7775
  Precision     0.4563
  Recall        0.6560
  F1-Score      0.5382
  ROC-AUC       0.8100

The probability output is used by the dashboard for risk analysis and
customer-level churn probability.

> The reported metrics come from the project's model-training notebook
> and should be interpreted in the context of this synthetic dataset.

## Customer Segmentation

K-Means clustering is used to create customer segments based on
customer/service characteristics.

The final dashboard labels the two resulting segments as:

-   **Low-Service Customers**
-   **High-Service Customers**

Current segment sizes:

  Segment                    Customers
  ------------------------ -----------
  Low-Service Customers          2,933
  High-Service Customers        27,067

The segmentation is separate from the churn target; churn-related
outputs are analyzed after the segments are created rather than being
used as the clustering target.

## Installation

Clone the repository:

``` bash
git clone https://github.com/Vasu123q/Customer-Churn-Dashboard.git
cd Customer-Churn-Prediction
```

Create a virtual environment:

### Windows

``` bash
python -m venv venv
venv\Scripts\activate
```

Install dependencies:

``` bash
pip install -r requirements.txt
```

## Run the Dashboard

The dashboard reads the prepared output file:

``` text
Output Data/Customer_clustered_result.xlsx
```

Run:

``` bash
streamlit run app.py
```

The application will open in your browser.

## Running the Data / ML Pipeline

The repository also contains the data-generation, cleaning, modeling and
segmentation workflow.

The main runner is:

``` bash
python File_runner.py
```

Model training and customer segmentation are also available through the
notebooks under:

``` text

unsupervised/
```

    retraining models on every application launch.

    project workflow reproducible and inspectable.
